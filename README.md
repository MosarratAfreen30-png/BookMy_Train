
# BookMyTrain - Java Console Application

A console-based railway ticket booking system built using Core Java.

## Features
- User registration and login
- Search trains by source and destination
- Book train tickets
- View booked tickets
- Cancel tickets
- Track available seats

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- HashMap
- Scanner

## How to Run
1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Run `IRCTCAPP.java`.
4. Follow the instructions in the console.

## Limitations
- Data is stored in memory and resets when the application restarts.
- This is a learning project, not a production railway booking system.
